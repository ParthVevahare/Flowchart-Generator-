Privacy Policy

Effective date: 7 November 2026

This Privacy Policy explains how Code to Flowchart (“the Service”) handles information when you use its code-to-flowchart generator and optional Google Sign-In cloud library.

Information we process

Guest use: You can edit code and generate diagrams without signing in. The editor processes code in your browser; using guest mode does not require uploading your source code to the cloud library.

Google Sign-In: If you sign in, Firebase Authentication/Google may provide an account identifier, name, email address, and profile photo, depending on the information available and permissions granted. Authentication services also process technical information to provide secure sign-in.

Saved code: If you use My Codes, your code, titles, library metadata, favorites, deletion/Trash state, and related settings are stored in Google Cloud Firestore associated with your account. You control what you choose to save. Email-update preferences may be stored; the Service currently does not send promotional email.

Browser and usage information: The Service uses browser storage for settings, temporary state and a cached visit total. A third-party counter at abacus.jasoncameron.dev receives a visit/count request and may receive standard technical request information, such as IP address and browser metadata, under its own practices. When you request a PDF export, a third-party script provider may receive normal network request information. The hosting provider may also process standard server logs.

Purposes and legal bases

We use information to authenticate users, save and retrieve private code libraries, provide editor features, protect against abuse, remember settings, and understand aggregate site visits. Where applicable, processing is based on delivering requested services, legitimate operational interests, or consent when legally required.

Providers and sharing

We use Google Firebase Authentication and Cloud Firestore to deliver sign-in and cloud saving, GitHub Pages for web hosting, and third-party resources for visit counting and optional PDF export. These providers may process data in other countries. We do not intentionally publish your private cloud library or sell your personal information. Information may be disclosed if required by law or needed to protect the Service.

Retention and deletion

Saved code remains associated with your account until you delete it, subject to the app's Trash/recovery behavior and any provider backup retention. Signing out does not delete stored data. To request deletion of your account-associated data, contact the maintainer using the link below; you may need to verify ownership of the account privately. Do not share sensitive information in a public issue. Browser storage can usually be cleared in your browser settings.

Security

We use Firebase account-based access rules and transport protections, but no online service can guarantee complete security. Avoid saving passwords, API keys, or other secrets in source code.

Children and privacy rights

If local law requires parent or guardian consent to use an online service, obtain it before signing in. You may have rights to access, correct, delete, or object to processing of personal information under applicable law. Contact the maintainer to make a request.

Changes

We may update this Policy as the Service changes. The effective date at the top will show when this version took effect.

Questions or privacy requests: contact the project maintainer via GitHub Issues. Do not post private account details or source code publicly in an issue.
