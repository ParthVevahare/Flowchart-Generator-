# Google sign-in branding

`google-signin.png` is the unmodified, pre-approved Light / Square / Android + Web / text-enabled @3x button from Google's official [branding asset bundle](https://developers.google.com/static/identity/images/signin-assets.zip), downloaded November 7, 2026.

It includes the official color Google G and button lettering. The website displays it proportionally at 198 × 44 CSS pixels inside a native button with an accessible name. Google's brand assets remain subject to the [Sign in with Google branding guidelines](https://developers.google.com/identity/branding-guidelines).
