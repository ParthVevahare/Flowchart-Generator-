Choose SVG, PNG or PDF

SVG keeps text and shapes as vector artwork and is useful when the destination supports scalable graphics. PNG is a raster image for documents, slides and tools that expect an image file. PDF uses a custom page that follows the diagram’s proportions for printing or sharing. Generate a current valid chart before opening Export.

PNG dimensions follow the diagram, with high-resolution rendering bounded to 8,192 pixels per side and 24 million pixels to protect browser memory. Very large diagrams are rasterized at a lower density; use SVG when you need the complete vector detail without that raster limit.

Tune the chart in Diagram settings

Open Settings from the diagram toolbar. Content controls change true and false labels, group adjacent simple statements, or decorate connector labels with a contrasting pill. Rendering controls choose the diagram theme, direction, width scale, height scale, font size and compact spacing.

Choose Monochrome for a restrained print diagram, or Classic, Ocean, Forest or Dark for a colored document. Direction can run top-to-bottom, bottom-to-top, left-to-right or right-to-left. Width scale changes node width and wrapping; height scale changes minimum node height. Larger fonts reserve more space in the natural-size diagram; there is no fixed paper frame shrinking the result.

Apply, cancel or restore defaults

Changes are staged in the dialog. Apply settings saves the preferences in this browser when storage is available and updates a current chart. Cancel or Escape closes the dialog without committing its edits. Reset to defaults resets the draft; use Apply to keep those defaults.

Preferences are device-local and separate from source code and the optional cloud library. They do not synchronize between browsers or accounts. If browser storage is blocked or full, the controls still work for the current visit and the app tells you that preferences could not be saved.

Troubleshoot exports and stale charts

If you edit source or change the language, generate again before downloading. This avoids exporting an old diagram that no longer describes the editor. PDF export loads its library on demand, so network restrictions can affect it; retry or use SVG or PNG if the PDF library cannot load.

Use the small example below to check the full workflow: generate, change the theme, apply, export, then inspect the file. Diagram settings change presentation and statement grouping; they do not change the source program or turn a structurally valid diagram into proof that the program is correct.

Common questions

Will the exported image match the selected theme?

Yes. The chart palette, branch labels, text size and layout are included in the generated diagram. The editor’s interface theme is a separate preference.

Does the PDF have to be A4?

No. The PDF page follows the diagram’s aspect ratio. Wide diagrams get wide pages and tall diagrams get tall pages, within the PDF format’s size limits.

Can I download without an account or watermark?

Guest users can export SVG, PNG and PDF without signing in. The generated chart does not add a promotional watermark.
